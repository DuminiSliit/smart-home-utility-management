# smart-home-utility-management
AI and IoT-based smart home system for electricity and water monitoring, utility prediction, and intelligent plant watering.

## Electricity monitoring module

The SparkSense electricity monitoring application is in [`electricity_module`](./electricity_module/). It contains the Expo mobile app, Flask API, ESP32 firmware, local Docker stack, and AWS infrastructure template. See its [README](./electricity_module/README.md) for setup instructions; run its commands from inside that directory.
